# Project Title

## Description
This project is a responsive component that allows users to:
- Select a range of days
- Add notes
- Works on mobile and desktop

## Tech Stack
- React / JavaScript / CSS (or whatever you used)

## How to Run Locally
1. Clone the repo:
   git clone <your-repo-link>

2. Install dependencies:
   npm install

3. Run the app:
   npm run dev

## Features
- Day range selection
- Notes feature
- Responsive design
